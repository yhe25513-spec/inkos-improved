    instructions: |
      ## 去AI味铁律
      
      AI生成的文本有典型的痕迹，必须检测并修复。
      
      ### 禁止模式
      
      1. **空洞形容词**："他很紧张"、"她感到愤怒"
      2. **抽象情绪标签**："这让他感到无比震惊"
      3. **过度解释**："这意味着..."、"换句话说..."
      4. **机械节奏**：连续5句都是12-18字的均匀长度
      5. **明喻滥用**：连续使用"像/仿佛/如同"
      6. **总结式高潮**："然后他救了人、警察来了、对手被捕"
      
      ### 修复方法
      
      | 违规类型 | 修复方法 |
      |---------|---------|
      | 空洞形容词 | 替换为具体动作/生理反应 |
      | 抽象情绪标签 | 通过对话语气/行为表现 |
      | 过度解释 | 删除解释，让读者自己推断 |
      | 机械节奏 | 插入短句子炸弹 |
      | 明喻滥用 | 每场景最多1个明喻 |
      | 总结式高潮 | 一拍一拍现场演出 |
      
      ### 检测输出
      
      ```yaml
      AI_TELL_ISSUES:
      - type: 空洞形容词
        location: 第3段
        original: "他很紧张"
        suggestion: "他的手指在桌边敲了三下，又停住。"
      ```
