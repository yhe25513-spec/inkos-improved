InkOS Studio UI 设计改进方案

基于现有架构的深度分析与渐进式重构建议 — 2026年6月

一、现状诊断 — 当前 UI 的问题

1.1 侧边栏：信息过载，导航效率低

严重

260px 宽侧边栏塞入了 5 个区域、8 个创作入口 + 书籍列表 + 会话历史 + 系统设置

侧边栏同时承担了「全局导航」「书籍管理」「会话管理」「系统设置」四个角色。用户每次打开都要面对密密麻麻的列表，找到想要的功能需要扫视大量信息。

Sidebar.tsx:269–587
严重

创作入口 8 个按钮平铺在侧边栏顶部，占据大量空间

"创长篇小说、短篇、同人、番外、仿写、续写、分支互动、自由互动" 8 个按钮以 2×4 网格挤在侧边栏前 1/4 区域。大部分用户只用其中 2-3 个，其余 5-6 个成为视觉噪音。

Sidebar.tsx:294–303
中等

书籍列表 + 会话列表嵌套过深

侧边栏需要展开书籍 → 展开会话 → 操作会话（改名/删除），三级嵌套。用户想切换到另一个会话需要 3 次点击：展开书 → 找到会话 → 点击更多菜单。

Sidebar.tsx:310–408
优化

侧边栏在书籍模式下与右侧 BookSidebar 功能重复

左侧 Sidebar 有"我的书架"，右侧 BookSidebar 又有"进度/章节/角色/设定/摘要"。两个面板都在展示书籍信息，用户容易困惑哪个才是正确的操作入口。

Sidebar.tsx vs BookSidebar.tsx

1.2 聊天界面：输入区过于拥挤

严重

模型选择器 + 快捷操作 + 配图按钮全部堆在输入框下方

ChatPage.tsx 的输入区底部同时展示了模型下拉选择器（含搜索框）、"查看世界"按钮、自动配图按钮。三者在同一行争夺空间，在小屏幕上严重拥挤。

ChatPage.tsx:678–716
中等

QuickActions 快捷操作条与输入区耦合

"写下一章、审计、导出、市场雷达" 四个快捷操作按钮作为独立条放在输入区上方，占据了本可用于消息显示的垂直空间。对于主要使用自由输入的用户来说，这些按钮几乎从不使用。

ChatPage.tsx:616–626, QuickActions.tsx
优化

Play 模式的配图设置在浮动菜单中，不易发现

自动配图功能藏在一个 Palette 图标按钮的弹出菜单里，需要 2 次点击才能打开，且菜单没有明确的视觉引导。很多用户不知道这个功能的存在。

ChatPage.tsx:718–762

1.3 仪表盘：缺少层次感

中等

Dashboard 页面没有明确的视觉层次

书籍卡片、Manuscript Foundry 面板、配置提醒全部在同一层级并列展示。用户进入后第一眼不知道该看哪里。没有"最近活跃"与"全部书籍"的区分。

Dashboard.tsx:187–379
优化

书籍卡片的操作按钮位置不够直观

每张书籍卡片右侧的"写下一章"按钮虽然醒目，但当书籍数量多时，右侧操作区会与左侧内容产生视觉割裂。且"统计分析"图标按钮太小，容易被忽略。

Dashboard.tsx:275–315

1.4 TUI 终端界面

优化

TUI 的配色方案温暖但对比度不足

终端主题使用暖色调 (#c88a56 强调色)，在大多数终端中对比度偏低，长时间阅读容易疲劳。消息类型的视觉区分（用户/助手/系统）仅靠颜色差异，色弱用户难以分辨。

theme.ts

二、设计方案 — 渐进式重构

核心思路：减少侧边栏的信息密度，将全局导航收缩为图标栏，将创作入口提升为仪表盘的一等入口，将输入区简化为单一焦点。

2.1 新侧边栏：从"信息面板"到"导航轨道"

当前
  • 260px 宽，占据屏幕约 20%
  • Logo + 8 个创作按钮 (2×4 grid)
  • 可折叠的书籍列表（含会话子项）
  • 可折叠的会话历史
  • 系统设置（4 个按钮）
  • 工具（4 个按钮）
  • 底部 Agent 状态
  • 总计：约 30+ 个可点击元素
新设计
  • 64px 窄图标栏，占屏幕 ~5%
  • Logo + 7 个图标按钮（悬停显示 tooltip）
  • 书籍列表移至仪表盘内
  • 会话历史移至 Chat 页顶部
  • 设置/工具移至右上角菜单
  • 底部无常驻元素（按需查看）
  • 总计：7 个常驻可点击元素

2.2 新仪表盘：创作入口前置 + 书籍卡片增强

设计要点

四大创作入口取代 8 个平铺按钮

将 8 个创作入口浓缩为 4 个卡片："长篇小说"、"短篇小说"、"开放世界"、"同人/仿写"。每个卡片显示简短描述，帮助用户快速决策。不常用的"番外"、"续写"等合并到"更多"中。

设计要点

书籍卡片增加封面、进度条、状态标签

每本书显示一个彩色封面占位符（根据类型着色）、章节进度条、当前状态标签。操作按钮从"写下一章"改为带状态的差异化按钮：写作中的书显示"继续"，审稿中的显示"审阅"。

设计要点

Manuscript Foundry 面板下沉

实时写作追踪面板只在有书籍正在写作时出现，且放在书籍列表下方作为"活动面板"而非并列展示。不写作时完全隐藏，减少视觉噪音。

设计要点

快捷操作从独立条变为内联胶囊

QuickActions 不再占据整行独立区域，而是作为输入框上方的内联胶囊组。它们始终可见但不抢占垂直空间。点击后直接发送，无需二次确认。

设计要点

模型选择器缩小为底部标签

模型选择从一个大下拉菜单缩小为一个紧凑的标签（"Claude Sonnet 4.6 ▾"），放在输入框左下角。点击展开搜索面板。不再在输入区底部占据显著位置。

设计要点

辅助功能图标移至右下角

自动配图、附件等辅助功能以小图标形式放在输入框右下角。Play 模式的"查看世界"按钮仅在 Play 模式下显示在右上角，平时隐藏。

2.4 TUI 终端界面：对比度增强 + 符号区分

当前
  • 强调色 #c88a56 对比度偏低
  • 消息类型仅靠颜色区分
  • 无明确的快捷键提示
  • slash 命令面板占用输入区空间
  • 执行状态仅靠文字描述
新设计
  • 提高强调色亮度至 #db9f6a
  • 消息类型用前缀符号区分（│ / ◆ / ·）
  • 输入框底部显示快捷键提示
  • slash 命令面板浮动在输入框上方
  • 执行状态用 ANSI 动画进度条

2.5 改动对比总结

方面 当前 改进后
侧边栏宽度 260px（固定） 64px（图标栏）
创作入口 侧边栏顶部 2×4 网格，8 个按钮 仪表盘内 4 个卡片 + "更多"折叠
书籍列表 侧边栏嵌套展开（书→会话） 仪表盘内卡片列表 + 进度条
会话管理 侧边栏底部，3 级嵌套 Chat 页顶部下拉切换
快捷操作 输入区上方独立条（占整行） 输入框上方内联胶囊
模型选择器 输入框下方大下拉（含搜索框） 输入框左下角紧凑标签
配图控制 浮动菜单，2 次点击 输入框右下角图标按钮
TUI 对比度 #c88a56 强调色 #db9f6a（提高亮度）
TUI 消息区分 仅靠颜色 颜色 + 前缀符号（│/◆/·）

三、实施建议 — 分阶段渐进迁移

第一阶段

收缩侧边栏（2-3 天）

将 Sidebar.tsx 从 260px 缩减为 64px 图标栏。所有文字标签和二级内容（书籍列表、会话历史）移出侧边栏。保留完整的点击导航功能，通过 tooltip 提示名称。这一步改动最小、收益最大，用户立刻感受到清爽。

第二阶段

重构仪表盘（3-4 天）

重新设计 Dashboard.tsx：4 个创作卡片 + 书籍卡片增强（封面、进度条、状态标签）。将 Manuscript Foundry 面板改为条件渲染。这一步完成后，新用户引导和日常操作都会更顺畅。

第三阶段

简化输入区（2-3 天）

重构 ChatPage.tsx 底部的输入区：快捷操作改为内联胶囊、模型选择器缩小为标签、辅助功能图标移至右下角。保持所有现有功能不变，只是重新排列布局。

第四阶段

TUI 微调（1-2 天）

调整 theme.ts 的配色方案提高对比度，在 dashboard.tsx 的消息渲染中增强符号区分，在输入框底部添加快捷键提示。
