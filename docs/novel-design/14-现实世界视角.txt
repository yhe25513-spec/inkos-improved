一、双线叙事结构
    ┌─────────────────────────────────────────────────────────────┐
    │  资源世界线（主线）：代表的探索、战斗、成长                 │
    │  现实世界线（副线）：地球各国反应、资源反馈、小人物故事     │
    │  切换时机：                                                 │
    │   · 每10章切换一次                                          │
    │   · 重大资源反馈时切换                                       │
    │   · 代表击败强敌时切换                                       │
    └─────────────────────────────────────────────────────────────┘

二、现实世界场景设计
    2.1 指挥中心视角
    ┌─────────────────────────────────────────────────────────────┐
    │  中国总指挥（张伟）：沉稳、果断，50岁左右，话不多             │
    │  首席战略分析师（苏教授）：苏瑶的姑姑，负责分析资源世界情报    │
    │  军方代表（李将军）：负责协调军事行动和资源分配               │
    │  场景：大屏幕前，众人盯着林天画面，偶尔沉默，偶尔低声交换意见 │
    │  不用每次都写"指挥中心一片欢腾"，用细节表达——张伟手指在桌面  │
    │  轻敲了三下、苏教授的笔停在半空、李将军点了一下头             │
    └─────────────────────────────────────────────────────────────┘

三、国家获得资源后的变化（写具体、有画面感）
    ┌─────────────────────────────────────────────────────────────┐
    │  不写"灵气浓度提升10%"，而是写——                               │
    │  秦岭深处，监测站的仪器发出尖锐的警报声。灵气数值在半小时内   │
    │  从0.12飙升到3.7。值班员盯着屏幕看了半分钟，才想起该上报      │
    │                                                             │
    │  不写"获得了一座矿脉"，而是写——                               │
    │  卫星图像显示，新疆塔克拉玛干沙漠某处出现了一条3公里长的矿脉 │
    │  带。地质学家连夜飞过去，飞机降落时还能看到矿脉在月光下闪着   │
    │  暗金色光芒                                                   │
    │                                                             │
    │  不写"获得修炼资质"，而是写——                                 │
    │  北京某中学体育课上，一个普通女生单手举起了300斤的杠铃。体  │
    │  育老师的眼镜掉在了地上，周围的同学忘了鼓掌                   │
    └─────────────────────────────────────────────────────────────┘

四、现实世界变化的节奏感
    ┌─────────────────────────────────────────────────────────────┐
    │  第1-80章：小范围变化（某村、某矿、某城市）                 │
    │  第81-180章：区域变化（某省、某山脉、某海域）                │
    │  第181-280章：全国变化（整个国家灵气复苏、基建重建）         │
    │  第281章以后：全球性变化（灵气扩散到其他国家、全球格局重塑）  │
    └─────────────────────────────────────────────────────────────┘

五、叙事原则
    ┌─────────────────────────────────────────────────────────────┐
    │  1. 小人物故事不超过3段，点到即止，读者脑补                   │
    │  2. 指挥中心对话要简短，用动作和沉默代替长篇大论              │
    │  3. 他国视角不丑化、不脸谱化，用"人的反应"而非"国家的反应"    │
    │  4. 资源反馈的画面感越强越好——味道、声音、温度都可以写        │
    │  5. 现实世界线永远"慢半拍"：林天做完了，地球才开始变          │
    └─────────────────────────────────────────────────────────────┘
