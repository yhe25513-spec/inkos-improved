═══════════════ 系 统 面 板 ═══════════════

一、系统来源
    ┌─────────────────────────────────────────────────────────────┐
    │  宇宙意志赋予，每个代表进入资源世界后自动激活                │
    │  无法关闭，但可以选择"隐藏"                                  │
    │  面板内容不每章都展示，只在关键节点展示                       │
    └─────────────────────────────────────────────────────────────┘

二、面板功能
    ┌─────────────────────────────────────────────────────────────┐
    │  1. 属性面板：展示代表基本信息、等级、战斗力                 │
    │  2. 任务面板：主线任务/支线任务（无每日任务）                │
    │  3. 资源面板：展示已获取资源及换算                           │
    │  4. 排名面板：国运积分排名（前50名）                         │
    │  5. 地图面板：已探索区域高亮、未探索区域迷雾、特殊地点标记   │
    │  6. 传承进度条：只有林天能看到（其他代表没有）               │
    │  7. 区域事件提示：在某区域停留3天以上可能触发随机事件        │
    └─────────────────────────────────────────────────────────────┘

三、林天的属性面板示例
    ┌─────────────────────────────────────────────────────────────┐
    │  姓名：林天                                                  │
    │  国家：中国                                                  │
    │  等级：F级（入流/炼气期）                                    │
    │  传承：齐天大圣（进度隐藏，不显示具体百分比）                 │
    │  战斗力：对外显示极低，实际随解锁飙升                         │
    └─────────────────────────────────────────────────────────────┘

四、国运积分排名面板
    4.1 排名规则
    ┌─────────────────────────────────────────────────────────────┐
    │  只显示前50名                                               │
    │  积分=资源等级换算，规则如下                                 │
    │  每20章更新一次                                             │
    │  排名变化用"红色上升/蓝色下降"标注                           │
    └─────────────────────────────────────────────────────────────┘

    4.2 资源等级换算表
    ┌─────────────────────────────────────────────────────────────┐
    │  F级  = 1 积分                                              │
    │  E级  = 5 积分                                              │
    │  D级  = 20 积分                                             │
    │  C级  = 100 积分                                            │
    │  B级  = 500 积分                                            │
    │  A级  = 2000 积分                                           │
    │  S级  = 10000 积分                                          │
    │  SS级 = 50000 积分                                          │
    └─────────────────────────────────────────────────────────────┘

    4.3 排名面板示例
    ┌─────────────────────────────────────────────────────────────┐
    │  1.  美国   约翰·史密斯   12,500   （↑2）                  │
    │  2.  俄罗斯 伊万·彼得罗夫 10,800   （↑1）                  │
    │  3.  日本   山本一郎      9,200    （↓2）                  │
    │  ...                                                       │
    │  8.  中国   林天          3,500    （↑42）                 │
    └─────────────────────────────────────────────────────────────┘

五、地图面板
    ┌─────────────────────────────────────────────────────────────┐
    │  已探索区域：高亮显示                                        │
    │  未探索区域：显示为迷雾                                      │
    │  特殊地点（遗迹/宝箱/Boss巢穴）：以特殊标记显示               │
    │  代表位置：实时显示                                          │
    │  其他代表位置：不可见（除非开启"探查"技能）                  │
    └─────────────────────────────────────────────────────────────┘

六、面板展示时机
    ┌─────────────────────────────────────────────────────────────┐
    │  1. 初次进入资源世界时（第一次展示完整面板）                 │
    │  2. 重大升级/突破时（展示属性变化）                          │
    │  3. 排名变化时（展示排名面板）                               │
    │  4. 获取稀有资源时（展示资源面板）                           │
    │  5. 触发区域事件时（展示事件提示）                           │
    │  6. 其他章节不展示面板                                      │
    └─────────────────────────────────────────────────────────────┘
