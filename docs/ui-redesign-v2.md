# InkOS Studio UI 重构方案

> **核心原则**：不动业务逻辑，只做信息架构重组 + 视觉层次重建。
> 目标：让用户在 3 秒内知道"我在哪、能做什么、下一步该做什么"。

---

## 一、当前界面问题诊断

### 问题 1：左栏太满 — 导航与功能混杂

你的左栏同时承载了 **4 种完全不同的角色**：

| 区域 | 内容 | 角色 |
|------|------|------|
| 开始创作 | 8 个创作入口 | 导航 |
| 我的创作 | 书籍列表 | 资源管理 |
| 会话记录 | 会话列表 + 新建 | 对话管理 |
| 系统 | 题材/模型/项目/守护/日志 | 设置 |

**问题**：
- 8 个创作按钮（长篇小说、短篇小说、同人、番外、仿写、续写、分支互动、开放世界）占了左栏 1/3 高度，但 90% 用户只用 2-3 个
- "我的创作"和"会话记录"都是树形列表，视觉上没区分
- 左栏 260px 宽，实际有效内容区域被严重挤压

### 问题 2：QuickCommands 彩虹按钮

[QuickCommands.tsx](packages/studio/src/components/QuickCommands.tsx) 里有 9 个按钮，每个用了完全不同的背景色：
- 蓝色写大纲、绿色写正文、红色修订、黄色体检、紫色存档、橙色检测、灰色状态、粉色伏笔、靛蓝角色

**问题**：
- 彩虹色块在文学创作工具里显得廉价，像 2010 年的后台管理系统
- 9 个按钮同时出现，用户不知道该点哪个
- 颜色编码没有语义（为什么写正文是绿色？审计应该是绿色吗？）

### 问题 3：BookDetail 页面按钮爆炸

[BookDetail.tsx](packages/studio/src/pages/BookDetail.tsx) 的 Tool Strip 一行放了 10+ 个按钮：
- 全部通过（批量）/ 真相文件 / 数据分析 / 质量评估 / 归并记忆 / 重修设定 / 计划 / 组装 / 导出下拉 + 复选框

**问题**：
- 这些按钮分属 3 个不同的抽象层级：高频操作（写下一章）、低频操作（归并记忆）、工具操作（导出）
- 全部平铺在一起，没有分组也没有优先级

### 问题 4：右栏 BookSidebar 信息密度过高

[BookSidebar.tsx](packages/studio/src/components/chat/BookSidebar.tsx) 的 PanelView 放了：
- 进度指示器 / 章节列表 / 角色列表 / 基础设定 / 摘要

**问题**：
- 这些内容其实都可以折叠成可展开的面板
- 角色列表和章节列表展示的是同类信息（都是列表），但没有分组

### 问题 5：输入区模型选择器位置尴尬

[ChatPage.tsx](packages/studio/src/pages/ChatPage.tsx:678-716) 的模型选择器放在输入框底部左侧，但：
- 用户发消息时不需要频繁切换模型
- 这个位置抢了用户的视觉焦点
- 下拉菜单向上弹出，被输入框遮挡

## 二、重构方案

### 方案概览

```
┌─────────────────────────────────────────────────────────────────┐
│  重构前                           │  重构后                       │
├─────────────────────────────────────────────────────────────────┤
│  ┌──────┐  内容区              │  ┌─┐  内容区                   │
│  │ 260px│                      │  │ │  内容区                   │
│  │ 全功能│                      │  │  内容区                   │
│  │ 侧边栏│                      │  │  内容区                   │
│  └──────┘                      │  └─┘                          │
│                                  │                               │
│  问题：左栏太宽，内容区挤         │  改进：64px 图标栏 + 内容区放大  │
└─────────────────────────────────────────────────────────────────┘
```

### 改动 1：左栏从 260px → 64px 图标栏

**保留**：Logo + 7 个核心图标（仪表盘/创作/聊天/开放世界/分析/配置/设置）
**移除**：所有文字标签、8 个创作按钮、书籍列表、会话列表
**新增**：鼠标悬停显示 tooltip

```
┌─────┐
│ I   │ ← Logo
├─────┤
│ ⌂   │ ← 仪表盘
│ ✦   │ ← 创作
│ 💬  │ ← 聊天
│ 🎮  │ ← Play
├─────┤
│ 📊  │ ← 分析
│ ⚙   │ ← 配置
│ 🛒  │ ← 设置
└─────┘
```

**为什么可行**：
- 书籍列表和会话管理移到内容区内部（仪表盘 + Chat 页顶部）
- 创作入口移到仪表盘（4 个大卡片，不是 8 个小按钮）
- 设置移到右上角菜单


- 颜色编码改为语义化的：写下一章用主色（oxblood），其他用中性色

## 三、渐进式实施路径

### Phase 1：QuickCommands 去彩虹化（1 天）

这是风险最低、收益最快的改动。

- 修改 [QuickCommands.tsx](packages/studio/src/components/QuickCommands.tsx)
- 去掉所有 `bg-{color}-500`，改用统一的中性色 + 主色
- 前 3 个常用操作突出显示，其余折叠
- 不改任何业务逻辑

### Phase 2：左栏收缩为图标栏（2-3 天）

- 修改 [Sidebar.tsx](packages/studio/src/components/Sidebar.tsx)
- 宽度从 260px → 64px
- 书籍列表和会话列表移到内容区
- 创作入口移到仪表盘

### Phase 3：仪表盘重构（2-3 天）

- 修改 [Dashboard.tsx](packages/studio/src/pages/Dashboard.tsx)
- 4 个创作卡片
- 书籍列表改为卡片式
- Manuscript Foundry 条件渲染

### Phase 4：BookDetail 重组（2-3 天）

- 修改 [BookDetail.tsx](packages/studio/src/pages/BookDetail.tsx)
- 主操作区精简
- 章节列表折叠
- 工具按钮分组

### Phase 5：输入区简化（1-2 天）

- 修改 [ChatPage.tsx](packages/studio/src/pages/ChatPage.tsx)
- 模型选择器缩小
- 快捷操作独立行

## 四、设计原则总结

1. **少即是多**：每个页面只保留 3-5 个主操作，其余折叠
2. **统一风格**：去掉彩虹色，用统一的语义化色彩
3. **内容优先**：左栏从 260px 缩到 64px，内容区放大 4 倍
4. **渐进披露**：常用操作默认显示，低频操作折叠
5. **不动逻辑**：所有改动仅限于视觉和信息架构，不改变任何业务逻辑
