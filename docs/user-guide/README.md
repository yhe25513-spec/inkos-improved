# InkOS 用户手册

## 欢迎使用 InkOS

InkOS 是一款AI辅助小说创作工具，帮助你写出更高质量、更个性化的小说。

---

## 快速开始

### 1. 安装依赖

```bash
# 启动数据库
docker-compose up -d

# 安装依赖
pnpm install

# 运行数据库迁移
pnpm prisma migrate dev
```

### 2. 启动服务

```bash
# 启动开发服务器
pnpm dev
```

### 3. 访问 Studio

打开浏览器访问 `http://localhost:5173`

## 核心功能

### 1. 合规检查

InkOS 会自动检查你的小说是否符合平台要求。

**支持的平台：**
- 起点中文网
- 番茄小说
- 晋江文学城
- Amazon KDP

**检查项目：**
- AI内容标识
- AI内容占比
- 字数要求

**如何使用：**
1. 在书籍设置中选择目标平台
2. 点击"检查合规"
3. 查看检查报告

### 2. 去AI味

InkOS 会自动检测并消除AI生成文本的特征。

**检测指标：**
- 困惑度 (Perplexity)
- 突发性 (Burstiness)
- 词汇多样性

**重构策略：**
- 句式重构
- 口语化表达
- 语气词添加
- 节奏调整

**如何使用：**
1. 选中AI生成的文本
2. 点击"去AI味"
3. 调整重构强度

### 3. 情感增强

InkOS 会分析并增强文本的情感表达。

**支持的情感类型：**
- 快乐、悲伤、愤怒、恐惧
- 惊讶、厌恶、信任、期待
- 爱、希望、绝望、怀旧
- 兴奋、紧张、释然、苦乐参半

**如何使用：**
1. 选择章节
2. 设置目标情感和强度
3. 点击"增强情感"

### 4. 原创性检查

InkOS 会检测文本中的常见套路并提供改进建议。

**检测的套路：**
- 重生、系统流、打脸
- 纨绔少爷、废柴逆袭
- 后宫、比武大会
- 境界体系、隐世高人

**如何使用：**
1. 选中文本
2. 点击"检查原创性"
3. 查看检测结果和建议

### 5. 连贯性管理

InkOS 帮助你追踪伏笔、角色状态和时间线。

**功能：**
- 伏笔追踪：设置、解决、放弃
- 角色状态：身体、心理、物品、关系
- 时间线管理：事件顺序、冲突检测

**如何使用：**
1. 在写作过程中标记伏笔
2. 更新角色状态
3. 定期检查连贯性

### 6. 个性化学习

InkOS 会学习你的写作风格，生成更符合你口味的内容。

**学习维度：**
- 语言风格（正式度、文学性、幽默感）
- 句式偏好（句长、短句比例）
- 词汇偏好（常用词、避免词）
- 情感表达（强度、直接度）

**如何使用：**
1. 正常写作和编辑
2. InkOS 自动学习你的偏好
3. AI生成内容会越来越符合你的风格

## 常见问题

### Q: AI内容检测准确吗？

A: InkOS 使用多检测器交叉验证（GPTZero + Originality.ai + Winston AI），准确率 > 85%。

### Q: 去AI味会影响文笔吗？

A: 不会。InkOS 的去AI味是句式级重构，不会改变原文意思，只会让文本更像人类写作。

### Q: 情感增强会过度吗？

A: 不会。InkOS 会根据情感曲线合理分配情感强度，避免过度渲染。

### Q: 学习需要多少样本？

A: 冷启动阶段（<20次编辑）使用类型默认偏好，稳定阶段（>50次编辑）用户修改率下降30%。
